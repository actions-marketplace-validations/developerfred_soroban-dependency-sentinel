Soroban Dependency Sentinel

Supply-chain security scanner for Soroban projects. Detects CVEs in your Rust dependency tree, measures pony-factor risk, and blocks CI when things go wrong.

View on GitHub Install from crates.io
cargo install soroban-dependency-sentinel

Why Sentinel

Two systemic risks are not mitigated by any existing tool. Sentinel fills the gap.

🔍

CVE detection

Scans Cargo.lock against OSV.dev (RustSec mirror) with a 24h local cache and offline mode.

👥

Pony factor

Resolves maintainer risk from three sources: PG Atlas → crates.io owners → local git log.

📊

Unified risk score

Combines CVE severity and pony factor into a single score with actionable mitigation plans.

🚦

CI gate

Fails builds when risk crosses a threshold. Emits SARIF 2.1.0 for GitHub Code Scanning.

🔌

Plugin system

Auto-discovers sentinel-plugin-* executables. Extensible without touching the core.

📄

5 output formats

JSON, SARIF, Markdown, text, and HTML. JSON Schema (draft 2020-12) for downstream tooling.

Quick start

terminal 
$ sentinel scan --path . --format text

serde                          1.0.229        0.00 Safe        1    CratesIoOwners
time                           0.1.44        1.80 Watch       2    CratesIoOwners

GitHub Action

Add one line to your workflow and let Sentinel block risky merges.

- uses: developerfred/soroban-dependency-sentinel@v1
  with:
    fail-on: high
    upload-sarif: "true"
